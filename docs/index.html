    06 / About

    GameLab Radar について

    GameLab Radar は、新しく公開されたゲーム関連の Web サイトを毎日自動で集めている個人サイトです。ゲームメディアが取り上げた公式サイト、ティザーサイト、特設・周年サイト、国内のデザインギャラリーに載ったゲームサイト、海外のインディーゲームまでを横断して収集しています。

    あわせて、事前登録受付中のタイトルと新作リリーススケジュールもまとめています。遊ぶゲームを探すときにも、サイトをつくるときの参考にも使えます。

    もうひとつの顔として、AI を相棒にゲームをつくる実験もしています。できたものは Games に並べています。制作の裏側は note に、日々の進捗は X に書いています。
