05 / About

GameLab について

GameLab は、AI を相棒にしてゲームをつくる個人の実験室です。「こんなゲームがあったら」を、企画からコード、絵や音まで AI と一緒に組み上げて、遊べる形で公開していきます。

あわせて、世界中で新しく公開されたゲーム関連サイトを毎日自動で集める Radar を運営しています。ティザーサイトや周年サイトのデザイン、インディーゲームの発表など、つくる側のヒントになるものを拾っています。

制作の裏側や気づきは note に、日々の進捗は X に書いています。
